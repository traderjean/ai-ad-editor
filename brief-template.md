# Ad brief

Fill this in and paste it to Claude with "Edit this ad". Every clip in the ad is AI-generated. The must-haves are required. Leave any optional line blank and the default is used.

## MUST-HAVE

- **Script:** paste the final script, or attach script.txt
- **Product name:**
- **What it is:** the product type and how it's used
- **What it does:** one line
- **Product photos:** attach 1 to 3 clear photos with the front label readable
- **Buyer:** age, gender, country
- **Their problem:** one line
- **Voiceover:** pick one
  1. I have it (attach the file)
  2. Generate it for me
  3. Talking characters (people on screen say the lines)
  4. AI talking avatar (attach the avatar video or a photo of the presenter, or I make one)
  5. No voiceover, text on screen

## OPTIONAL (blank = default)

| Field | Options | Default |
|---|---|---|
| Hooks | how many, and your hook lines if you have them | 1 hook: the script's first line |
| Look | anything: 3D animated, 2D cartoon, motion graphics, cinematic, photoreal phone footage, your own reference | you choose in Step 2 |
| Main character | age, look, job | 3 options suggested from the buyer |
| Their day | 2 or 3 real moments from their life, and who's around them | I suggest some |
| Explanation lines | simple 3D animation / visual metaphor / lifestyle only | simple 3D animation |
| Pace | a new shot every 2 to 3 seconds / one shot per line | every 2 to 3 seconds |
| Captions | Bold / Clean / None | Bold |
| End card or offer | text, discount, link | none |
| Logo and brand look | logo file, fonts, colours | none |
| Avoid | claims, words or visuals that are off-limits | none |
| Reference ad | a link or video to match the style of | none |
| Platform | Meta / TikTok / YouTube Shorts | Meta |
| Sizes | 9:16 / 4:5 / 1:1 / 16:9 | 9:16 |
| Shorter cuts | 15s / 30s | none |

The product, photos, buyer, logo, brand look, avoid list and end card are saved for the brand, so the next ad for the same brand only needs the script, the voiceover choice and the hooks.
